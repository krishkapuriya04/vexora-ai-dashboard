# VEXORA Assets

Static asset directory for images, icons, and media files.

## Structure

- `images/` — Product screenshots, logos, and marketing imagery
- `icons/` — SVG icons and favicon assets

## Usage

Reference assets with relative paths from the project root:

```html
<img src="assets/images/dashboard-preview.png" alt="VEXORA Dashboard" loading="lazy">
```
